# 🎓 EduVerse - AI-Powered Online Learning Platform

EduVerse is a full-stack, enterprise-grade learning management system (LMS) designed to deliver modern, interactive e-learning experiences with real-time AI tutoring, interactive quizzes, live virtual classrooms, and comprehensive student progress analytics.

---

## ✨ Key Features

- 🤖 **Interactive AI Tutor (Gemini 2.5/Flash)**: Real-time contextual explanations, code review, lesson summarization, and dynamically generated practice quizzes.
- 📚 **Comprehensive Course Catalog**: Multi-module curriculum covering Generative AI, Full-Stack Architecture, Cloud Microservices, and UI/UX Design.
- 💻 **Live Code Sandbox & Workspace**: Interactive code execution preview, syntax highlighting, and practical exercises.
- 🎥 **Virtual Classrooms**: Live video streaming interface with integrated student chat, hand-raising, and real-time polls.
- 💬 **Discussion Forums & Channels**: Topic-based threads, verified instructor answers, and collaborative problem-solving.
- 📊 **Progress & Analytics Dashboard**: Real-time progress tracking, course completion badges, and verifiable certificates.
- 🗄️ **Dual Database Architecture**: Native MongoDB Atlas integration with automated fallback to high-speed persistent storage and MongoDB Compass export tooling.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Motion
- **Backend**: Node.js, Express.js
- **AI Integration**: Google Gemini API (`@google/genai`)
- **Database**: MongoDB & MongoDB Atlas (with in-memory failover engine)
- **Build & Tooling**: Vite, ESBuild, TSX
